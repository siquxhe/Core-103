# 4n · #86 L4 量产综合形态 · 整链路资源与时序复核

> 关联：`4g-引擎子系统装配综合与背靠背加压及dbg量产移除.md`（引擎子系统口径基线）、`4e-P0-1路线甲落地...md`（整核收敛基线）、`4h-装载器与固件叠加启动路线方案设计.md` §L4、`4m-60...闭环复核.md`。
> 器件：`GW1NSR-LV4CQN48PC6/I5`（FF 3573 / BSRAM 10 / LUT 4608）；综合器 GowinSynthesis 1.9.11.03（Education）。
> 口径：综合通过 ≠ 功能正确 ≠ 时序收敛；Fmax 为无 SDC 综合估算，真实时序以 P&R 为准。

## 1. 结论先行

- 新建**整链路综合装配顶层** `fullchain_wrapper`：内核 `core_top`（含内部 memory + 写仲裁器）+ `copy_engine` + `engine_ctrl` 同一网表连通，跑通 Gowin 综合 `exit 0`，主存进 **8 块 BSRAM**，无 IF0008 / RP0001 / 多驱动 / 意外 Latch / 组合环。
- 整链路资源快照（综合估算，**wrapper 无激励，FF/LUT 偏低估，仅作量级参考**）：**BSRAM 8 / FF 931 / LUT 1030 / ALU 99 / Fmax 59.976 MHz / Level 9**。
- 本轮定位两个装配缺口：① `core_top` 未引出仲裁背压 `cpu_stall/eng_stall`，整链路 `wr_stall` 暂 tie 0；② 综合顶层无激励导致 `start_reg` 等内核通路被优化切除，精确资源需带激励综合或上板复核。
- 仍阻塞在无板 / 路线 B 的三项：loader 可综合化、P&R 真实时序、显例化 BSRAM 原语，移交上板阶段，不在本轮纯软件范围。

## 2. 三口径综合基线对照

| 整核 | `core_top`（synth-converged） | 8 | 598 | 785 | 64 | 64.452 | 10 | 未接引擎 / ctrl / loader |
| 引擎子系统 | `engine_subsys_wrapper`（synth-engine） | 4 | 816 | 825 | 65 | 55.404 | 10 | 不挂内核 |

## 3. 装配与连线口径

`fullchain_wrapper` 连线对齐 `tb_engine_ctrl.v` 既有仿真装配关系：

- **eng 旁路**：`copy_engine` 读/写 ↔ `core_top` 内部 memory；
- **ctrl 旁路**：`engine_ctrl` 命令块读写 ↔ `core_top` 内部 memory；
- **命令块本地寄存器**：`core_top.cmd_wr_*` → `engine_ctrl.local_wr_*`；
- **ctrl ↔ engine**：`cmd_src/dst/len/go`、`ack_done/ack_err`、`busy/done/err/err_code`；
- **dbg 调试口**：量产形态 tie 0，不连内部逻辑；
- **内核 dev/pnl 面板输入**：综合统计顶层 tie 0（无激励保活，不参与资源评估）。

### 3.1 变体文件

- `regress/synth-fullchain/fullchain_wrapper.v` — 整链路装配顶层（综合统计用，非交付 RTL）；
- `regress/synth-fullchain/memory.v` — memory 剥离变体副本（与 `synth-engine/memory.v` MD5 一致 `02366B84…`）：CPU 主读 + eng 旁路双同步读，ctrl/dbg 组合读归零，dbg 写剥离，命令块写旁路保留；
- 正本内核子模块 / `core_top` / `arbiter` / `engine_ctrl` / `copy_engine` 直接引用正本 RTL。

## 4. 综合告警归类

| 告警 | 现象 | 判定 |
| --- | --- | --- |
| `EX3073` Port `cpu_stall` remains unconnected | `core_top` 未把仲裁器背压引出到顶层 | **既有装配缺口**；整核 converged 基线同样存在。整链路 `copy_engine.wr_stall` 暂 tie 0 |
| `NL0002` module `start_reg` swept in optimizing | 综合顶层无激励，`start_reg` 预置通路被优化切除 | **wrapper 无激励死代码切除**，非 RTL 缺陷；精确资源需带激励综合或上板复核 |
| （对照 converged）`CV0016/18` eng/ctrl/dbg 旁路口 unused | 整链路中引擎 / ctrl 已真实连通，此类悬空告警消除 | 整链路装配连通性成立的佐证 |
| 无 `IF0008` / `RP0001` / 多驱动 / Latch / 组合环 | — | 主存与仲裁队列均推断为存储单元，结构无异常 |

## 5. 资源量级自洽性核对

- **BSRAM 8**：主存数组仅一份，与整核基线 8 一致；引擎子系统基线 4 为其变体自身口径，不可比。
- **FF 931** = `u_core` 517 + `u_eng` 111 + `u_ctrl` 303。`u_core` 517 低于整核基线 598，差额来自无激励扫掉的 `start_reg` / 部分 io / arith 通路（见 §4 NL0002）。
- **LUT 1030** = 430 + 159 + 441；量级与两基线叠加后区间相符，无异常偏大的冗余寄存器数组。

## 6. 开放项与移交

| 项 | 现状 | 归属 |
| --- | --- | --- |
| loader 可综合化 | 路线 A 模型含 `$readmemh` initial 块 + `img[4096]` 数组 + integer 遍历，不可综合；量产路线 B 替换 SPI NOR 字流 | 上板改造 / 4h §3 §7，本轮不改解析校验逻辑 |
| P&R 真实时序 | 无板、无 SDC；59.976 MHz 为综合估算 | 上板阶段，#86 后续 |
| 显例化 BSRAM 原语 | 当前为综合推断 BRAM；位宽 / 字节使能 / 单双口口径未定 | 上板阶段 |
| 仲裁背压端口引出 | `core_top` 未直通 `cpu_stall/eng_stall`；整链路 `wr_stall` tie 0 | 后续若需整链路背压闭环，在 `core_top`（修改派生件）直通 stall 端口 |
| 整链路精确资源 | wrapper 无激励，部分内核通路被切除，FF/LUT 偏低估 | 需带激励综合或上板后复核 |

## 7. 仿真与综合边界说明

- 整链路**功能连通性**由既有仿真回归覆盖：`tb_engine_ctrl` / `tb_fw_poll` / `tb_cpu_eng_concur` / `tb_engine_backpressure` 等（#60 复核 8 套全 PASS，`core-eb` MD5 `75af629…` 对齐）。
- 本 `fullchain_wrapper` 仅用于 Gowin 综合资源 / 连接检查，**不参与 iverilog 回归基线**；行为仿真仍走正本 `memory.v` + 既有 tb。
- 综合产物 `build/` 按惯例不入库；变体源码（wrapper + memory 副本）随正本 / 副本双份同步。
