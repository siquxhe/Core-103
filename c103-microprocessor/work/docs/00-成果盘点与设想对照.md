> 日期：2026-11-25 ｜ 口径：本文件是 `c103-microprocessor/work/` 正本工作区的**当前实现状态锚点**；结论与判据数来自 `work/regress/*.log` 第一手日志与 `work/docs/` 落地记录。

## 1. 一句话现状

设想阶段规划的"协作式固件 + 硬件拷贝引擎"已经从 C 原型走到 **RTL 装配 + 端到端装载/握手闭环 + 综合复核**：引擎 FSM、写仲裁、命令块控制、镜像装载器、固件轮询 ACK 链路均已仿真通过；尚未做的是多段背靠背固件循环、同拍争写定向用例、纯硬件自举与整核量产综合/P&R 上板。

### 2.3 内核集成副本（`work/ip_core/`）

- `core/`：原 103 内核子模块副本（arith_unit / arith_ctrl / operator / pulse_unit / select_reg / start_reg / io_unit / core_top / memory），既有克隆仓库原位未改。

- `tb/`：18 个 testbench（核心端到端、引擎 ctrl/mem、背靠背加压、固件轮询、loader-core/loader-fw、指令/传送/减法/绝对值覆盖、并发等）。
- `run_*.ps1`：各套件回归脚本；`test/` 与 `case.hex/bin`：镜像与参考输出。

### 2.4 镜像打包与校验链路

- 打包器 `image-pack`（tape-converter 侧）：段定义 + `.103` → 结构化镜像（目录头 + 段表 + 镜像体 + 校验尾）。
- 校验和口径：**统一 mod 2^31**（`IMG_SUM_MASK = 0x7fffffff`），符号位参与累加；与数据字数值域掩码 `IMG_VALUE_MASK`（低 30 位）显式区分。4i 已统一打包器、模拟器、RTL loader 三方口径。
- 固件镜像：`regress/l3-loader-firmware/` 下 `fw_l3a/l3b/l3c` 的 `.103` 源与 `.seg` 段定义。

## 5. 遗留与下一步（按优先级）

**已闭环（本轮对照旧台账清偿）**：多段背靠背固件循环（#83）、仲裁同拍争写加压（#84）、仲裁 FIFO 边界定位 + 互斥形式验证（#87）、RAM 读延迟/读缓冲闭环（#60 仿真+综合范围）、L4 整链路综合复核（#86 综合口径）。

**剩余开放项**：

1. **loader 可综合化**：`image_loader` 含 `$readmemh` initial 块 + 数组遍历，不可综合；量产路线 B 替换为 SPI NOR 控制器读回字流，解析/校验口径两侧共用。
2. **P&R 真实时序**：无开发板、无 SDC；59.976 MHz 为综合估算，关键路径与 Fmax 以布局布线后报告为准。
3. **显例化 BSRAM 原语**：当前为综合推断 BRAM；位宽 / 字节使能 / 单双口口径待上板阶段定。
4. **仲裁背压端口引出**：`core_top` 未直通 `cpu_stall/eng_stall`，整链路 `wr_stall` 暂 tie 0；需整链路背压闭环时在 `core_top`（修改派生件）直通。
5. **整链路带激励综合**：当前 wrapper 无激励，部分内核通路被切除；精确 FF/LUT 需带激励综合或上板复核。
6. **entry 自举旁路落地（可选，L4 前置）**：评估已完成，推荐方案乙（顶层联锁复用 arr_strt，不改 `start_reg.v`）；落地时补自举 tb，回归不回退。
7. **形式验证补全**：队列不溢出（项数 ≤ DEPTH）、跨周期不丢守恒需影子计数器/RTL 内 `ifdef FORMAL` 断言；当前由仿真守恒计数覆盖。
8. **S011 片选/位掩码边界用例**：8 片选译码与 BWEN 分位写边界在扁平数组模型中未覆盖。
9. **上板**：缺板级约束（`.cst/.sdc`）、下载链路与真实外设接线；当前无开发板。
10. **闲置位利用（L4 候选，4o）**：方向 A 主存奇偶校验暂缓（31→32 扩总线穿透内核派生链路、只检不纠、缺错误处置通路）；方向 B 固件 / 数据段写保护为前置预留——段表 `flags[30:27]` 取 1 位定义只读标志，loader 留解析扩展点，写口拦截电路待路线 B 接 NOR 时落地。本轮不改 RTL / 打包器。
