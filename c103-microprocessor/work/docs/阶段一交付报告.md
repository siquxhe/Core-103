## 6. 拷贝引擎原型设计要点

- **寄存器**（对应 07 文档 §3）：`src/dst/len`（12 位）、`go`（脉冲）、`busy/done/err`、`err_code`、`entry`（可选）。
- **FSM**（7 态）：`IDLE → ARM → FETCH → WRITE → CHECK → DONE/ERR`；`ARM` 做边界检查，`CHECK` 判 `remain==0` 转 DONE；DONE/ERR 停留等待握手清除，不自行迁移。
- **边界检查**：零长度、源区间越界、目的区间越界分别编码；越界时不写目的区。
- **内存抽象**：引擎不持有内存所有权，外接 `src_mem/dst_mem` 指针与容量，便于将来替换为 RTL 行为 RAM 或 Flash 模型。
- **代码位置**：`work/engine/copy_engine.{h,c}`；测试台 `work/tb/test_engine.c`；构建 `work/Makefile`。
