# 4q · 配套语言子集技术规格：Fortran II 静态定点编译子集

> 关联：`4p-配套语言子集与FPU配套选型评估.md`（选型结论）、`02-现代类比与可行性评估.md` §2（既有推演）、`指令集兼容性核对.md`（命令表/寄存器分工）、`4h-装载器与固件叠加启动路线方案设计.md`（装载链路）、`4r-FPU协处理器技术规格细化.md`（浮点后端预留）。
> 口径：本文件为**编译器前端/后端规格草案**，尚未实现；数值与指令口径以模拟器 `simulator/src_c/103.c` 与 RTL 为准，区分已核实事实、设计草案、未知存疑。
> 范围：一期定点标量 + 一维静态数组；浮点表达式、解释器、递归/堆/动态存储均不在一期。

## 1. 定位与范围

### 1.1 形态

- 宿主侧（PC）编译器：把类 Fortran II 源码解析、静态分配、代码生成，投影成 `.103` 机器码文本，再经现有 `image-pack` → `image_loader` 链路装载；**目标机纯执行，无常驻解释器**。
- 编译器、符号表、解析器全部在宿主侧，不占目标机主存。

### 1.2 一期排除项

| 排除 | 原因 / 前置 |
|---|---|
| 递归、可重入子程序、动态调用 | 无 CALL/RET 硬件、无栈帧；静态约定不可重入 |
| 堆、动态分配、动态数组 | 无堆机制；全部静态定长 |
| 字符串与文本运算 | 现有 I/O 只到单字数；字符行通路待路线 B |
| 浮点数 | 待 4r FPU 规范冻结后由后端扩展接入 |
| 解释型 REPL | 见 4p §4 路线乙，暂缓 |

## 2. 数值与类型模型（已核实口径）

### 2.1 字与符号—数值码

- 数据字 31 位：`bit30` 符号位，`bit29:0` 数值位；数值域掩码 `0x3fffffff`，符号位 `0x40000000`（`103.c` / `image_format.h`）。
- 符号—数值码：正负由符号位区分，数值位不取补码；零的符号位规则沿用模拟器（结果为零时符号取第二操作数符号，`do_add/do_sub` 等）。
- bit31 预留恒 0，语言层不得使用。

### 2.2 定点定标

- 加法 / 减法：不缩放，直接按符号—数值码加减（`do_add` / `do_sub`）。
- 乘法：`(a × b) >> 30` 定标右移（`do_mul`）。
- 除法：`(b << 30) / a` 定标左移（`do_div`）。
- 语言层表达式必须暴露这条定标口径：乘除不是普通整数乘除，源码注释与类型说明需标明定点标度；具体标度因子（1.30 等）由规范文档冻结，本规格只对齐现有算法规约。

### 2.3 溢出与错误

- 现有口径：加减结果超出 `±0x3fffffff`、乘除结果超域，模拟器打印 `overflow` 并退出（`do_add/do_sub/do_div/do_mul`）。
- 一期语言层按**溢出即错误停机**建模：不做饱和算术、不做回绕、不置可恢复状态位；溢出检测时机与是否报源码行号，列入 P1 原型待验证。
- 逻辑乘（按位与）不产生溢出，符号位取第二操作数（`do_and`）。

### 2.4 类型

| 类型 | 一期支持 | 说明 |
|---|---|---|
| 定点标量 | 是 | 符号—数值码，30 数值位 |
| 一维定长数组 | 是 | 元素同为定点标量，连续存放 |
| 布尔 | 否（以数值符号位替代） | 条件判断直接判符号位 |
| 浮点 / 复数 / 字符 / 串 | 否 | 见 §1.2 |

## 3. 程序结构与语法草案

### 3.1 结构

```
program   ::= { const-decl | var-decl | array-decl } { subroutine } main-block
subroutine ::= "SUB" 名 "(" 参数槽列表 ")" 语句序列 "RETURN"
main-block ::= 语句序列 "END"
```

- 主程序与子程序共享同一静态地址空间；参数经固定静态槽传递（见 §7）。
- 标签用于 GOTO / GOSUB 回填；变量名、标签名字母开头，短名（一期限 1–6 字符，字符集限大写字母 + 数字）。

### 3.2 语句（BNF 草案）

```
stmt ::=  "LET" 变量 "=" 表达式
        |  "IF" 关系 "THEN" 标签
        |  "GOTO" 标签
        |  "GOSUB" 标签
        |  "RETURN"
        |  "PRINT" 变量
        |  "INPUT" 变量
        |  数组元素 "=" 表达式
        |  "REM" 注释
        |  "END"

关系  ::= 表达式 ("=" | "<" | ">" | "<=" | ">=" | "<>") 表达式
expr  ::= 项 { ("+" | "-") 项 }
项    ::= 因子 { ("*" | "/") 因子 }
因子  ::= 常量 | 变量 | 数组元素 | "(" expr ")" | "-" 因子
```

- 一期关系运算仅出现在 `IF` 条件，不赋值到变量。
- 一元取负在编译期转为符号位处理；无自增/自减、无复合赋值。

### 3.3 示例（伪源码 → 机器码意图）

```fortran
REM 求和: S = S + A(i)
LET S = S + A(I)
```

编译意图：取 `A(I)`（常量下标时直接算地址）→ 与留存的 `S` 经加法指令相加 → 写回 `S`；借结果留存链减少中间传送（见 §5）。

## 4. 静态分配模型

### 4.1 主存区间（2048 字基线，4096 扩容上限）

| 区间 | 内容 | 分配方式 |
|---|---|---|
| 程序段 | 生成的机器码指令序列 | 代码生成按条顺序排布 |
| 常量段 | 源码常量、字面量 | 编译期去重建表 |
| 变量段 | 标量静态变量 | 每标量 1 字，符号表登记地址 |
| 数组段 | 一维定长数组元素 | 每元素 1 字，基址 + 连续偏移 |
| 临时槽 | 表达式中间值、表达式暂存 | 编译期按作用域复用固定槽 |
| 返回槽 | GOSUB 返回地址 | 每个子程序 1 个静态槽（一期禁嵌套） |

### 4.2 符号表

- 编译期一次性完成：名字 → 主存绝对字地址；**无运行期重定位、无符号查找表**（目标机不存名字）。
- 数组登记：基址、长度、元素类型；下标编译期可定值时直接展开为绝对地址。
- 临时槽分配：按表达式树深度复用；无栈，槽位在编译期静态定死。

## 5. 表达式编译模型

### 5.1 累加器分工（已核实）

| 寄存器 | 角色 |
|---|---|
| A | 第一操作数 |
| B | 第二操作数；同时留存上次算术结果，供 op1=2/3 复用 |
| C | 本次算术结果 |
| D | 并行加法器与进位链，**非通用寄存器**，不可作为变量分配 |

### 5.2 结果留存链

- 算术结果落 `C`，随即留存到 `B`（`103.c`：`reg_b = reg_c`）。
- `op1=2/3` 变体取 `c1 + 上次结果（留存 B）`；代码生成优先复用这条链，把"上一步结果"直接作为下一步操作数，省掉一次内存传送。
- 写回变体 `op1=0/2/4/6` 把结果写回 `M[c2]`；`op1=4/6` 附带打印。编译器按语句是否需要写回/打印选择 op1 变体。

### 5.3 二元运算 → 指令映射

| 源码算子 | op2 | 译码动作 | 备注 |
|---|---|---|---|
| `+` | 0 | 加 | `do_add` |
| `-` | 1 | 减（第二地址 − 第一地址） | `do_sub`；源码减法顺序需对齐该语义 |
| `/` | 2 | 除（第二地址 / 第一地址） | `do_div`，定标左移 |
| `*` | 3 | 乘（第二地址 × 第一地址） | `do_mul`，定标右移 |
| `AND` | 6 | 按位逻辑乘 | `do_and` |

### 5.4 表达式树到指令序列

- 求值左结合；按表达式树后序生成：叶子取数到累加器/临时槽，内部节点借留存链合并。
- 无求值栈：跨节点的临时值落 §4.1 临时槽；槽位不足时编译期报错（容量错误，非运行期扩容）。
- 减法/除法操作数顺序与机器语义相反（§5.3），代码生成需交换操作数顺序，避免源码与机器语义错位。

## 6. 控制流编译

### 6.1 条件（IF）

- 关系比较先编译成减法判符号：结果符号位 `bit30` 为负 → 条件转移 `34` 取 `c1`，非负 → 取 `c2`（`103.c` 034 译码）。
- 编译器把 `IF 关系 THEN 标签` 展开为：比较指令 + 条件转移 + 跳过块；关系算子到符号判据的映射（=、<>、<、>、<=、>=）在 P1 原型补齐真值表。

### 6.2 无条件跳转（GOTO）

- 映射 `24` 转移：`PC = c1`，上次结果写 `c2` 并留存 B（`103.c` 024）。标签地址两遍编译回填。

### 6.3 子程序（GOSUB / RETURN）

- **无 CALL/RET 硬件**：`GOSUB` 编译为——把返回地址（下条指令地址）写入该子程序的静态返回槽 → `24` 跳转到子程序入口；`RETURN` 从返回槽取回地址跳转。
- **不可重入**：返回槽静态唯一，一期禁止子程序嵌套调用与递归；并发/重入需求属路线乙议题（4p §9）。
- 参数经静态参数槽传入，返回值经固定结果槽带回；不保存/恢复通用寄存器（无通用寄存器堆可存）。

### 6.4 两遍回填

- 第一遍：扫描语句、分配地址、收集标签 → 地址映射；第二遍：回填 GOTO/GOSUB/条件转移目标地址。

## 7. 数组寻址

### 7.1 常量下标（一期支持）

- 下标为编译期常量：`基址 + 下标 × 1` 直接算出绝对地址，生成取数/写回指令。
- 编译期静态边界检查：下标越界在编译期报错。

### 7.2 非常量下标（存疑，一期不保证）

- 本机无变址、无间接寻址，指令地址字段为 12 位绝对地址；循环变量作下标时，需运行期改写指令地址字段（基址 + 偏移经算术修改指令字），或经基址槽间接拼装。
- 该编码方式、码长与副作用（改写指令字的自修改代码风险）列为 P1 原型待验证项；一期语法允许写非常量下标，但编译器在无法静态定值时给出"未支持"报错，不生成不可靠代码。

## 8. 子程序与运行库桩

| 桩 | 对接指令 | 说明 |
|---|---|---|
| 传送 | `05/15` Пч | `M[c1] → M[c2]`，留存 AU 第二数寄存器 |
| 输入 | `07/27` Вв | 纸带/输入介质录入一数 → `M[c2]` |
| 打印 | `45/55` 传送打印；`46/66` 算术打印 | 结果送打印通路 |
| 停机 | `04/14/44/54/17/37/57/77` 变体 | 主程序 `END` 落停机变体 |

- 一期不设独立库调用协议；常用操作以静态展开或上述桩内联。

## 9. I/O 语义对接

- `INPUT 变量`：对接 `07/27` 录入，数值落入对应变量主存单元；八/十进制录入沿用模拟器进制开关（`-D` BCD 录入）。
- `PRINT 变量`：对接 `do_output_reg_c` 打印单字数值；八/十进制输出沿用输出开关。
- **文本/字符串输出、提示符、逐字符终端输入不在一期**；依赖路线 B 串口/面板字符通路（4p §9）。

## 10. 代码生成到镜像链路

- 编译器产物为 `.103` 文本（地址@ ±操作码 c1 c2 格式，对齐现有 `test-program` 基线）。
- 经 `image-pack` 打包为结构化镜像（目录头 + 段表 + 镜像体 + 校验尾），`image_loader` 装载；入口 PC 由段表 `entry` 给出。
- 段表映射：程序段 / 常量段 / 数据段；段表 `flags[30:27]` 预留位本期不占用（见 4o）。
- 生成镜像须通过现有装载校验和口径，不破坏冻结基线 MD5。

## 11. 体积模型

### 11.1 字数估算

- 代码字数：按语句/表达式类型标定平均码长（指令条数 × 每指令 1 字）；平均码长由 P1 原型用中等算例实测反推，本规格不预设固定值。
- 数据字数：`标量数 + 数组元素数 + 临时槽数 + 返回槽数`，每字 1 个 31 位字。
- 临时槽/返回槽计入数据段，不计入代码段。

### 11.2 容量判据

- 基线 2048 字；中等程序超 2048 时依赖 4096 扩容区。高位地址（4000–7777）当前镜像低半区，扩容译码口径待扩容设计时明确（指令集核对 §5）。
- 编译器在分配阶段输出代码/数据字数估算；超预算在编译期报错，不生成超界镜像。

## 12. 存疑与待原型验证

| 项 | 状态 | 待验证 |
|---|---|---|
| 非常量下标寻址编码 | 存疑 | 自修改指令字 vs 基址槽方案；码长、副作用、可靠性 |
| 表达式临时槽深度上限 | 存疑 | 典型表达式树深度下的槽位复用率 |
| 关系算子真值表 | 草案 | =、<>、<、>、<=、>= 到符号判据的完整映射 |
| 中等程序码长 | 存疑 | P1 原型实测单条语句平均码长，回填体积模型 |
| 溢出源码定位 | 存疑 | 报错能否回映源码行号；一期可只报停机 |
| 十进制/八进制换算边界 | 存疑 | 录入/输出进制开关与定点定标的交互 |

## 13. 与 FPU 后端的预留衔接（指向 4r）

- 语法层预留浮点类型与浮点算子位置；一期不开放浮点字面量与浮点表达式。
- 后端衔接点（待 4r 规范冻结）：浮点操作数经静态槽送入 FPU 命令块 → 轮询完成 → 取回结果与状态标志；调用约定与操作数传递协议见 `4r`。
- 定点通路语义不因浮点后端改动；FPU 为隔离协处理器，不参与主核节拍链。

## 14. 与既有台账关系

- 本规格为 4p 选型结论的语言侧细化，不产生可综合 RTL，不进入 iverilog 回归基线。
- 对应 00 盘点开放项第 12 条（配套语言子集原型）；P1 宿主原型启动前，本规格的存疑项需在原型中逐项闭合或显式标注限制。
