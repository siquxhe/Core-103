## 2. 机器事实核对（外部史料 ↔ 本地实现）

| 项目 | 外部史料 | 本地实现 | 一致性 |
|---|---|---|---|
| 数制 | 二进制定点，30 数值位 + 1 符号位 | 30 数值位（`0x3fffffff`）+ 符号 bit30，bit31 保留 | 一致 |
| 指令格式 | 双地址；6 位操作码 + 2×12 位地址；指令符号位任意 | `[30]符号 [29:24]op [23:12]c1 [11:0]c2` | 一致 |
| 累加器 | 4 个触发器寄存器 А / В / С / Д；Д 为并行 30 位加法器与进位链，非通用寄存器 | `reg_a/reg_b/reg_c` + `reg_d` 占位；RTL Д 由组合加法器 + `carry_in` 实现 | 一致 |
| 操作数布局 | А：加数/减数/乘数/除数；В：加数/被减数/被除数；С：乘数；逻辑乘操作数在 А、С | 与 `arith_unit.v` 寄存器分工对应 | 一致 |
| 结果去向 | 加/减/乘结果落 В 再送 С；除/逻辑乘结果落 С 再送 В；结果同时留存 В/С 供下条复用 | `103.c` 运算后结果回送 B、留存供 op1=2/3/6/7 复用 | 一致 |
| 标配存储 | 磁鼓 2048 字；接第二个 ЗУ 柜可扩至 4096 字 | RTL 物理 2048 字；模拟器分配 4096 字（扩容上限） | 一致（口径见 §5） |
| 节拍 | 异步"命令-应答"；一条指令 8 节拍（0–7） | `pulse_unit.v` 节拍分配；C 模型为行为级不建模节拍 | 架构一致；时序细节属 RTL 层 |

## 3. 命令逐条对照

### 3.1 算术 / 逻辑乘（op2 主操作）

| op2 | 史料操作 | 本地译码 | 一致性 |
|---|---|---|---|
| 0 | 加 сложение | `order_add_to_ac` | 一致 |
| 1 | 减 вычитание（第二地址减第一地址） | `order_sub_to_ac` | 一致 |
| 2 | 除 деление（第二地址 / 第一地址） | `order_div_to_ac` | 一致 |
| 3 | 乘 умножение（第二地址 × 第一地址） | `order_mul_to_ac` | 一致 |
| 6 | 逻辑乘 логическое умножение（按位与） | `order_and_to_ac` | 一致 |
| 其余（4、5、7） | 史料未定义为主操作 | 仅作传送/转移/停机类译码 | 一致（无算术含义冲突） |

### 3.2 辅助特征 op1（高 3 位）

| op1 | 史料含义 | 本地 `103.c` / `operator.v` | 一致性 |
|---|---|---|---|
| 0 | 取 c1、c2；结果写回 M[c2] | 写回路径 | 一致 |
| 1 | 取 c1、c2；结果不写回 | 不写回路径 | 一致 |
| 2 | 取 c1 + 上次结果（留存 В）；写回 | 复用 B 上次结果 + 写回 | 一致 |
| 3 | 取 c1 + 上次结果；不写回 | 复用 B 上次结果 + 不写回 | 一致 |
| 4 | 同 0，额外打印输出 | 写回 + 输出 | 一致 |
| 5 | 同 1，对两数取模（绝对值）后运算 | 取绝对值 + 不写回 | 一致 |
| 6 | 同 2，额外打印 | 复用 + 写回 + 输出 | 一致 |
| 7 | 同 3，对两数取模 | 复用 + 取绝对值 + 不写回 | 一致 |

### 3.3 传送 / I/O / 转移 / 停机命令

| 史料码 | 史料代号 | 史料动作 | 本地模型 | 一致性 |
|---|---|---|---|---|
| `07` `27` | Вв 输入 | 纸带读入一数 → M[c2]，不留存寄存器 | `order_input_to_io`；`103.c` 录入 c2 | 一致 |
| `05` `15` | Пч 传送 | M[c1] → M[c2]，留存 AU 第二数寄存器 | 存数路径，结果入 B | 一致 |
| `45` `55` | ПчП 传送打印 | M[c1] → M[c2] 并打印，不留存 AU | 取数输出路径 | 一致 |
| `24` | ПУ 转移 | 下条取 c1；上次结果写 c2 并留存 AU | 跳转 c1，B 存 c2 | 一致 |
| `64` | ПУП 转移打印 | 同 24，结果同时打印 | 跳转 + 输出 | 一致 |
| `74` | ПУ 转移 | 下条取 c2；AU 留存上次结果绝对值 | 清 B 符号位，跳转 c2 | 一致 |
| `34` | УП 条件转移 | 结果为正取 c2，为负取 c1 | 按 B 符号分支：负→c1，否则 c2 | 一致 |
| `04` `14` `44` `54` | 停机 | 停机；变体差异为 AU/СР/ПР 预置内容 | 取数预置 A/B 后退出 | 一致 |
| `17` `37` `57` `77` | 停机 | 同上，共 8 个停机变体 | 寄存器传送 + 取绝对值变体后退出 | 一致 |

## 4. 核对结论

1. **本地命令集与 M-3 原始命令表逐条吻合**：博物馆命令表列出的全部算术、逻辑乘、传送、I/O、转移、停机命令，本地 RTL 译码与 C 模型均有对应路径。
2. **未发现外部史料中有、而本地未覆盖的命令**；也未发现本地模型自造的、史料无据的独立命令。
3. 本地 `103.c` 遇未识别操作码直接报错退出——这是保守处理，不影响已覆盖命令的兼容性。

## 5. 存疑与待确认项

| 项 | 现状 | 处置建议 |
|---|---|---|
| 存储容量口径 | 史料标配 2048 字、可扩 4096；RTL 2048、模拟器分配 4096 | 与史料一致：2048 为标配，4096 为扩容上限。RTL 高位地址（4000–7777）目前镜像到低半区，扩址设计时再明确 |
| 停机 8 变体的寄存器预置细节 | 本地以"预置寄存器后 break"建模；史料仅说明变体差异在 AU/СР/ПР 预置内容，未给逐位真值表 | 若需面板人工再启动级别的精确还原，需查原始《103 机程序汇编》或图纸；当前行为级建模不影响程序运算兼容性 |
| 算术变体全矩阵 | 博物馆实例仅列举部分编码（如 00/10/20/30/40/60/70、01、02、03、06、66、76）；其余 op1×op2 组合按变体规则生成 | 规则已在 `operator.v` 译码落地；如需逐码真值确认，待原始手册 |
| 十进制 BCD / 八进制录入输出 | 史料支持十进制或八进制打印；C 模型已建模 `-D` BCD 录入与 `-S` 输出后停机 | 面板脉冲/开关时序仍归 Verilator 链路覆盖 |
