# 4e · P0-1 路线甲落地：命令块剥离本地寄存器组与回归/综合复核

> 关联：`4d-P0-1端口收敛探针-BRAM可行性验证.md`（甲乙路线对比与推荐甲）、`4c-Gowin综合复核-BRAM推断定位.md`（阻碍定位）、`4a-M3-103容量调研与BRAM改造方案.md` §7.4 分层口径。
> 口径：资源数以 `*_syn_rsc.xml` 的 `T_` 总计为准；Fmax 为综合估算，无 SDC 约束。
> 器件：`GW1NSR-LV4CQN48PC6/I5`（FF 3573 / BSRAM 10 / LUT 4608）。

## 1. 结论先行

按 4d 推荐的**路线甲**，命令块八字（八进制 2400–2407）已从主存剥离为 `engine_ctrl` 本地寄存器组，主存端口收敛到 **单写 + 双同步读** 的双口 BRAM 模板。落地后：

- **仿真全量零回退**：内核 11 套 + IO 三例 + 独立通路三档全部 PASS，基线 MD5 与判据数逐项对齐改造前基线；
- **综合复核持平 4d 探针**：收敛形态综合 exit 0，主存进 **8 块 BSRAM**，**FF 598**（脱离改造前 63488 DFF 超限阵列），无 IF0008 / RP0001 报错。

| 指标 | 改造前现状（4c） | 4d 收敛探针 | 4e 路线甲落地（本文件） |
| --- | --- | --- | --- |
| 综合退出 | 失败 IF0008 | 成功 exit 0 | **成功 exit 0** |
| 主存形态 | 63488 DFF 阵列 | BSRAM 块 RAM | **BSRAM 块 RAM** |
| BSRAM | 0 | 8（80%，分母 10） | **8（80%，分母 10）** |
| FF | 63488（超限） | 598（17%） | **598（17%）** |
| LUT / ALU | — | 785 / 64 | **785 / 64** |
| Fmax / Level | 未取得 | 64.45 MHz / 10 级 | **64.452 MHz / 10 级** |

> 命令块本地寄存器组（8×31）随 `engine_ctrl` 装配层综合，归小寄存器，不占块 RAM；写仲裁器两路队列仍归 FF/LUTRAM。

## 3. 设计要点与数据流

### 3.1 命令块布局与本地索引

| 八进制地址 | 索引 | 字名 | 方向 |
| --- | --- | --- | --- |
| 2400 | 0 | SRC 源地址 | 参数写（CPU/纸带、dbg 预填） |
| 2401 | 1 | DST 目的地址 | 参数写 |
| 2402 | 2 | LEN 搬运字数 | 参数写 |
| 2403 | 3 | GO 启动标志 | 参数写；装配后自清 |
| 2404 | 4 | BUSY 状态镜像 | 状态写（ctrl 双写） |
| 2405 | 5 | DONE 状态镜像 | 状态写 |
| 2406 | 6 | ERR 状态镜像 | 状态写（bit0=err，bit[2:1]=err_code） |
| 2407 | 7 | ACK 握手字 | 状态写；装配后自清 |

地址低三位 `addr[2:0]` 即本地索引（2400–2407 连续对齐），无需全地址译码表。

### 3.2 两条写源与双写口径

- **参数旁路写（local_wr）**：`memory` 检测到外部写命中 2400–2407，经 `cmd_wr_*` 透传到 `engine_ctrl.local_wr_*`，同拍写本地 `cmd_q`。覆盖 CPU/纸带功能写与仿真 dbg 预填两条来源。
- **状态镜像双写（wr_req_r）**：`engine_ctrl` FSM 产出的 BUSY/DONE/ERR/ACK 写，同拍写两份——本地 `cmd_q`（供本模块本地读）与主存副本（经 `ctrl_wr → 仲裁器` 落数组，供 CPU 固件经主读口轮询）。
- 两个写源由上层装载/装配时序错开：参数写发生在装载期，状态写发生在装配/搬运期，不写同一索引；同拍不同索引时非阻塞赋值各写各元素。同拍同索引覆盖顺序：本地写块内 `wr_req_r` 分支在后，为最后有效值。

### 3.3 本地读规避 BRAM 一拍延迟

`ctrl_rd` 改为本地 `cmd_q` 组合读，无一拍 BRAM 延迟，`engine_ctrl` 紧凑 FSM 节拍保持不变，规避 4b 实测的 ctrl 同步读滞后一轮回归。`ctrl_rd_data` 端口在正本保留（装配层/主存副本读路径兼容），`engine_ctrl` 自身不再消费该信号。

## 6. 模型分层与遗留

### 6.1 分层口径（沿用 4d §5）

- Gowin 综合器 CLI 无 `-D` 宏注入参数，`ifdef` 双模型不可行；iverilog 跑全端口行为数组模型保基线，综合喂收敛端口模型，二者经文件/目录切换。
- 正本 `memory.v` 本轮仍保留 dbg 仿真通路与 ctrl/dbg 组合直读（供 tb 预填/直读校验）；上板量产形态整口移除，硬件预填/加载通路留待 P0-2 Flash/ROM 链路定。综合形态由 `regress/synth-converged/` 变体剥离，正本行为模型不参与综合资源评估。

### 6.2 尚未闭环

- **本地/副本一致性**：参数写与状态写的同拍同索引冲突，当前靠装载/装配时序错开保证；多轮搬运回归（engine-ctrl、fw-poll、concur）已覆盖常规节奏，极端背靠背装载场景如需再加压可补定向用例。
- **真实双口连接复核**：变体中 eng 读口在 `core_top` 未接引擎（旁路悬空，CV0016/18）；真实双口连接下的 BSRAM 块数与读路径 Fmax，待 wrapper 接 `copy_engine` 激励后复核。
- **engine_ctrl 装配层综合**：本地 `cmd_q`（8×31）随装配层综合，其 FF/LUT 占用尚未在含 `copy_engine`/`engine_ctrl` 的完整装配网表上统计；P0-1 后续补完整装配 wrapper 综合。
- 本复核无 SDC 时钟约束，Fmax 64.452 MHz / Level 10 为综合估算，真实时序以 P&R 后报告为准。
- 综合变体 `build/` 产物按惯例不入库；变体参考模型 `synth-converged/memory.v` 随正本端口演进同步刷新。
