# 4r · FPU 协处理器技术规格细化（Zuse 风格自定义浮点）

> 关联：`04-FPU集成设想.md` §7（路线甲选定与暂定格式草案）、`4p-配套语言子集与FPU配套选型评估.md`（配套定位）、`4q-语言子集-FortranII静态定点技术规格.md`（编译器后端衔接）、`4h-装载器与固件叠加启动路线方案设计.md`（命令块轮询模型）、`指令集兼容性核对.md`（主核指令边界）。
> 口径：本文件为**工程落地侧规格草案**；格式位域以 `04` §7.6 暂定表为准，本文件补数据通路、接口握手、编码预留与验证边界。规范冻结前不进 RTL、不进回归基线；区分已核实事实、设计草案、未知存疑。

## 1. 定位与保真边界

### 1.1 形态

- 独立协处理器：主核保持 31 位定点、符号—数值码原语义；浮点运算由 FPU 完成，**不改动内核定点数据通路**。
- 耦合方式：主核经命令/数据握手把操作数送入 FPU，轮询完成状态后取回结果；**FPU 不参与主核节拍链**，避免牵动原机脉冲时序（04 §5）。
- 定位：研究/教学增强项，不改变"103 原生只做定点"的历史事实（04 §6）。

### 1.2 保真边界（沿用 04 §2）

| 层 | 可否改动 | 说明 |
|---|---|---|
| ISA / 定点语义 | 保真 | 定点指令行为、溢出/取模/符号规则保持原机口径 |
| 外设与表示层 | 可重写 | 浮点表示、打包格式、I/O 呈现可现代定义 |
| 浮点指令编码 | 需新增 | 原指令集无浮点码，编码空间与触发方式另定 |

## 2. 浮点格式（路线甲，暂定草案，位域以 04 §7.6 为准）

### 2.1 字长与位域

- **31 位单字**，与原机字长对齐；双字浮点槽留作后续扩展，本期不做。
- 位域划分：`1 符号 + 7 位阶 + 23 位尾数`；**隐藏位是否启用待最终定**——启用则尾数有效位 24。
- 阶码采用**偏置码**（不沿用 Zuse 带符号阶），偏置值待规范冻结；偏置码用于简化比较/对齐电路。

### 2.2 舍入与下溢

- 舍入：一期只做**截断**；就近舍入列为后续可选项。
- 下溢：**不做渐进下溢**；flush 到零或 ∞ 并置状态标志；非规格化数不建模。

### 2.3 特殊值与状态标志

- 特殊值：`±∞` + 一个"未定义"（NaN 类），对齐 Z3/Z4；参与运算规则待真值表冻结。
- 状态标志：溢出 / 下溢 / 除零 / 无效，经协处理器状态回写，主核轮询读取。

### 2.4 待冻结格式项

偏置值、隐藏位取舍、特殊值编码与参与运算真值表、零/符号规则、十进制出入换算格式（04 §7.6 待细化项）。

### 2.5 与定点定标的区分

- 定点小数定标（乘 `>>30`、除 `<<30`）是原机算法规约；**浮点 FPU 不继承该定标**，另设尾数/指数格式（04 §3）。
- 语言层定点表达式与浮点表达式在后端分流，互不借用定标口径（见 4q §13）。

## 3. 数据通路分解（借 Z3/Z4 双通路思路）

### 3.1 双单元划分

- **指数单元**与**尾数单元**左右分离：一组寄存器与 ALU 处理指数（对齐、比较、阶运算），另一组处理尾数（加减/乘除、规格化），不混在一条通路（04 §7.3-1）。
- 浮点值以**寄存器对 `(指数, 尾数)`** 成对存放，对应 §4 浮点上下文槽（04 §7.3-2）。

### 3.2 运算 FSM 节拍（草案）

```
取操作数 → 特殊值先行判定 → 指数对齐 → 尾数运算(加/减/乘/除)
        → 规格化 → 舍入(截断) → 写回结果与状态标志
```

- 特殊值（±∞ / 未定义）在通路入口先行判定并透传，不进入普通尾数运算（04 §7.3-3）。
- 节拍划分是 FPU 内部状态机，不挂主核 8 节拍命令—应答链。

### 3.3 算子集

| 纳入一期 | 参照可选 | 不纳入硬件 FPU |
|---|---|---|
| 加、减、乘、除 | 开方、MAX/MIN、符号位测试 | 正弦等慢速算子（Z4 步进开关类，04 §7.3-4） |

### 3.4 不可照搬项（04 §7.4）

- 继电器/步进开关串行载体在 FPGA 上无对应物，只继承算法与状态划分。
- Z3/Z4 纸带串行控制模型不照搬；本 FPU 外壳是内存映射命令块 + 轮询握手。
- 语义非 IEEE-754：无现代偏置阶码惯例、无渐进下溢、早期截断舍入、∞/未定义规则自成一套；不能对标准浮点库直接对拍。
- 继电器速度数字（加 0.8s / 乘 3s）不传导到 RTL，上板只看数据通路级数与 Fmax。

## 4. 接口与握手

### 4.1 命令块/上下文槽布局（草案，地址段待主存规划定）

| 槽位（草案） | 方向 | 含义 |
|---|---|---|
| 操作数 A 槽 | 主核 → FPU | 第一浮点操作数（指数/尾数对） |
| 操作数 B 槽 | 主核 → FPU | 第二浮点操作数 |
| 算子码槽 | 主核 → FPU | 加/减/乘/除/测试选择 |
| 结果槽 | FPU → 主核 | 运算结果（指数/尾数对） |
| BUSY / DONE / ERR | FPU → 主核 | 忙 / 完成 / 错误状态镜像 |
| 状态标志槽 | FPU → 主核 | 溢出 / 下溢 / 除零 / 无效 |

- 布局复用引擎 ctrl 的命令块轮询范式（参照 4h §2.2：参数槽 + GO + BUSY/DONE/ERR + 回执）；具体地址段、字宽与双字槽排布待主存区间规划与格式冻结后定。

### 4.2 握手时序

1. 主核写操作数 A/B、算子码，置启动位；
2. FPU 置 BUSY，执行运算；
3. 完成后置 DONE，写结果槽与状态标志；错误置 ERR 与对应标志；
4. 主核轮询 DONE/ERR，取回结果与标志；FPU 自清状态，回 IDLE。
- 无中断：主核全程轮询，与协作式固件轮询模型一致（04 §5）。

### 4.3 写主与仲裁

- FPU 结果/状态回写与引擎搬运写、CPU 写共用现有写仲裁队列轮转，**不扩第三写主**（沿用 4h §3.2 命令块单一写主、装载期/运行期不并发原则）。
- 命令块区间旁路与仲裁对齐拍数，需在 RTL 原型阶段以波形核对（参照 4h §7.4 待核项）。

## 5. 指令编码与触发预留

### 5.1 触发方式（待评估二选一）

| 方式 | 说明 | 权衡 |
|---|---|---|
| 命令块触发 | 主核写浮点命令块，FPU 轮询消费；与引擎搬运同构 | 不动主核译码，隔离最彻底；一期倾向 |
| 新增浮点操作码 | 在主核译码入口加浮点码，直接触发 FPU | 需扩主核译码面，触及保真边界，暂缓 |

### 5.2 助记符映射层

- 汇编/宏层浮点算子到浮点操作码或命令块序列的映射（04 §4.2）；该层也是 4q 编译器后端的落点。
- 编码空间、操作数长度（单字/双字槽）随格式规范冻结后定义；一期不在主核定点指令表里塞浮点码。

## 6. 数值 oracle 与验证边界

### 6.1 独立 oracle

- 对照定点 oracle 做法，另建 **Python 浮点数值 oracle**，按自定义格式规则生成期望值与边界用例（04 §4.2）。
- 因语义非 IEEE-754，oracle 须自建全套规则：偏置阶、隐藏位、截断舍入、flush 规则、±∞/未定义运算真值表；不能依赖现代浮点库结果直接对拍。

### 6.2 边界用例

- 零、符号位、规格化数；非规格化数标注"不建模"；溢出、下溢、除零；±∞ 参与运算；未定值参与运算与传播。

### 6.3 回归护栏

- 现有定点 17 PASS 基线与镜像 MD5 基线保持不破坏；FPU 用例独立成组，不混入定点回归。
- FPU 通路未落地前，语言/编译器不生成浮点命令块序列（4q §13 预留接口）。

## 7. 与语言后端的衔接（指向 4q）

- **浮点调用约定**：操作数与结果在主存/协处理器间的传递协议（04 §4.2）；对齐 §4 上下文槽布局。
- 编译器后端把浮点表达式投影为：写操作数槽 → 置启动 → 轮询 DONE → 取回结果与标志 的命令块序列。
- **依赖顺序**：先冻结 04 格式规范与 Python oracle → 定操作数传递约定与触发编码 → 再谈 FPU RTL 数据通路；定点子集（4q）先行，不等 FPU。

## 8. 待冻结项与分期

| 阶段 | 目标 | 前置 |
|---|---|---|
| F1 格式规范 + oracle | 冻结位域/偏置/隐藏位/特殊值真值表/零符号规则/换算；Python oracle 落地 | 不依赖 RTL |
| F2 上下文槽 + 握手原型 | 命令块/上下文槽布局、轮询握手时序仿真、状态标志回写 | F1 冻结；复用 ctrl 轮询模型 |
| F3 数据通路 | 指数/尾数双单元、运算 FSM、舍入与规格化 | F2 握手贯通 |
| F4 编码接入 | 触发方式落地、助记符映射、编译器后端浮点序列 | F3 通路验证；4q 后端就绪 |

## 9. 存疑

| 项 | 说明 |
|---|---|
| 单字精度上限 | 31 位单字尾数精度能否覆盖中等科学算例；不足时双字槽是否需提前预留地址与搬运约定 |
| 偏置阶权衡 | 选偏置阶简化比较/对齐，但与 Zuse 带符号阶历史叙事的距离；最终偏置值待电路估算 |
| 标志处置通路 | 溢出/除零/无效标志上报后，主核是停机、置状态还是跳过，需与语言错误模型对齐（4q §2.3） |
| 上下文槽容量 | 浮点寄存器对数量、可并发挂起的浮点操作数，受 2048/4096 字预算约束 |

## 10. 与既有台账关系

- 本细化不产生可综合 RTL，不改动既有定点回归基线；对应 04 FPU 候选（00 盘点开放项第 11 条）的工程落地侧拆分。
- 格式结论以 `04-FPU集成设想.md` §7 为准；本文件与 `4q` 互为配套：4q 管语言/编译器侧，4r 管协处理器硬件/接口侧。
