## 2. 现状三栏

### 2.1 已核实的事实（附来源）

**加载通路只有纸带符号流，无结构化镜像。**



* simulator 主存为扁平数组 `machine_mem`，`malloc(sizeof(num_t)*04000)`（4096 字）；`init_mem()` **只分配、未 memset 清零**，未覆盖地址为 malloc 垃圾值（来源：`103.c:44-46`）。

* 唯一程序 / 数据装载入口是 `do_input()`：解析纸带符号流 ——`SET_ADD`(0x01) 设地址 `reg_addr`，`WRITE`(0x06) 把 `reg_c` 写入 `machine_mem[reg_addr]`；`POS/NEG` 拼符号，`NUM0..9` 拼数字，`END_ARR`(0x07) 结束（来源：`103.c:226-271`，符号码 `tape.h:1-18`）。

* `main.c` 启动序：`set_pc(0)` → `fopen(input.bin)` → `init_mem()` → `do_input(0)` 纸带预填 → `run_machine()`（来源：`main.c:27,64-73`）。

* tape-converter 汇编方向：输入 `.103` 文本行 = 4 位八进制地址 + 符号 + 10 位八进制指令字；逐行发 `NUM… SET_ADD 符号 NUM… WRITE`，末尾 `END_ARR`。输出**扁平地址 - 值纸带序列**，无目录头、无段表、无校验和（来源：`tape-converter/src_c/main.c:28-84`；`test-program/09_strt/input.103` 行样例）。

* 源码 grep 目录 / 镜像 / 校验 / ROM/Flash 关键词：除 `init_mem`（内存分配，非镜像加载）外 **0 命中**（来源：simulator 全量源码；tape-converter 三子目录）。

**RTL / Verilator 侧同样无镜像加载器。**



* 内核主存 `mem[0:WORDS-1]`（31 位）与独立通路 `mem_ram_model.v`（WORDS=4096）均**无&#x20;**`initial`**/**`$readmemh`**&#x20;初始值**；上电内容不定，仿真靠测试台经 `dbg_wr_*` 逐字预填，或走 IO 纸带通路写入（来源：`mem_ram_model.v:42,46-56`；各 `tb_*.v` 的 `dbg_wr_en` 预填段）。

* Verilator 验证链：`sim_input.v` 用 `$fopen("test/input.bin")` + `$fread` 逐字节读纸带，拆 5-bit 符号流送 74lv165 输入链；`sim_output.v` 反向写 `output.bin`。装载仍走真实 IO 输入通路，没有镜像 / 目录解析模块（来源：`sim_input.v:54-66`、`sim_output.v:54-66`）。

**现有生成 / 回归链**（来源：`tools/regenerate-test-program.ps1:3,38-60`）：



```
helper.py(固定种子) → input.103 → char2tape → input.bin(纸带)
   → simulator 执行 → output.103 → char2tape → output.bin(纸带)
```



* 中间产物 `input.bin` 是纸带符号流，不是结构化镜像；冻结参考在 `test-program/<case>/`（`input.103/input.bin/task.seq/output.103/output.bin`）。

**既有 "多段" 概念是命令块硬编码，不是段表。**



* 引擎三段搬运（程序段 / 常量段 / 数据段，各自源区→运行区）已在 2b/P1-4 链路验证；段参数（SRC/DST/LEN/GO）经命令块 2400–2407 下发，由测试台 / 固件逐段写命令字。当前**没有一张可被加载器遍历的段描述表**（来源：`2b引擎接入共享RAM进展.md` §286；`engine_ctrl.v` 命令块布局）。

### 2.2 合理推断（说明推理链）



* 现有 `input.bin` 本质就是 "扁平镜像"：地址 - 值序列的纸带编码。要脱离调试口 / 纸带独立启动，需要一个**结构化镜像容器**：目录头（魔数、段数、入口、版本）+ 段表（源 / 目的 / 字数 / 类型 / 标志）+ 镜像体 + 校验和。因为当前三段搬运的源 / 目的 / 长度已客观存在，只是散落在测试台命令字里，提炼成段表是自然映射。

* 目录项字段可在 31 位字口径内编码：两个 12 位地址 + 12 位长度 + 类型 / 标志，单字放不下，按 **2 字一段描述项** 组织（见 §4.1）。

* P0-2 与 P0-1 独立并行：块目录 / 校验不依赖主存是否进 BSRAM（3a §7 依赖图已标）；本轮不阻塞 P0-1 已落地成果。

* 校验和在复刻场景下主要检传输 / 装载错误，不防篡改；实现复杂度从简，按字累加和即可满足，CRC 属可选加固。

### 2.3 未决项（已在 §5.2 给出推荐，待确认冻结）

* **固化介质形态**：**已定外挂 SPI NOR Flash**（§5.1）；仿真镜像模型先行，SPI 控制器/引导 FSM 留上板（§5.3）。

* **校验算法与粒度**：累加和 vs CRC；整体一份校验和 vs 逐段校验。现有代码无任何先例可参照；推荐见 §5.2-2。

* **段类型枚举与段数上限**：103 无显式栈概念，是否需要栈段；程序 / 常量 / 数据之外是否留保留类型。推荐见 §5.2-4。

* **镜像文件物理格式**：二进制烧录映像 vs 文本清单；与现有 `input.bin` 纸带并存还是替代。推荐见 §5.2-3。

* **装载前是否清零主存**：当前 `init_mem` 未 memset，基线依赖纸带全覆盖；推荐见 §5.2-5。

* **段表源地址口径**：镜像体内紧凑偏移 vs 12 位绝对源地址。推荐见 §5.2-6。

## 4. 落地方案草案

### 4.1 分层：先仿真镜像闭环，SPI NOR 引导预留接口



* **路线 A（本轮目标，纯仿真闭环）**：主机侧打包结构化镜像文件；simulator 与 RTL 测试台经新增「镜像加载器」读目录、校验校验和、按段写入运行主存、置入口 PC。沿用现有 iverilog / C 模拟器回归口径，每个增量有可回归出口。

* **路线 B（上板形态，本轮预留不实现）**：外挂 SPI NOR Flash + SPI 主控制器 / 引导 FSM，上电由引导模块从 NOR 读目录与镜像体、校验后逐段搬入主存。待有板级对照或 P0-1 综合形态稳定后再做；接口在路线 A 加载器上预留（段表 / 校验口径两侧共用），边界见 §5.3。

### 4.2 镜像容器格式（草案，32 位字容器）

按字序排列，目录在前、镜像体在中、校验和收尾：



> 下表为早期草案；**冻结口径以 §5.4 镜像布局为准**（32 位字容器、NOR 字节偏移、段类型 0/1/2）。

| 区域  | 字位       | 字段                                                               | 位宽建议      | 说明                                       |
| --- | -------- | ---------------------------------------------------------------- | --------- | ---------------------------------------- |
| 目录头 | 字 0      | 魔数 MAGIC                                                         | 31 位      | 固定识别值（如 `31'h103103`），标识合法镜像。            |
| 目录头 | 字 1      | 段数 N；入口 PC；版本 / 校验算法标识                                  | `[11:0]`/`[23:12]`/`[30:24]` | 段表项个数 ≤ 16。 |
| 段表  | 每段 2 字・A | 目的地址 dst `[11:0]`；body 内字索引 off `[23:12]`；段类型 `[26:24]`；标志 `[30:27]` | 12+12+3+4 | 类型：0=程序段、1=常量/数据段、2=保留。路线 A off 为镜像体内 0 起始字索引（×4 即字节偏移）；24 位绝对 NOR 字节偏移留待路线 B 段表扩第三字（见 §5.4 落地偏差）。 |

| 校验尾 | 末字       | 整体校验和                                                            | 31 位      | 覆盖目录头 + 段表 + 镜像体；累加和先行，CRC-16 预留（§5.2-2）。             |

> 目录项是控制字，不套用数据字的符号位语义。

### 4.3 校验算法候选



| 候选                     | 检错能力             | C 侧实现 | RTL 侧实现     | 适用                     |
| ---------------------- | ---------------- | ----- | ----------- | ---------------------- |
| 按字累加和（mod 2³¹，符号位单独累加） | 检随机 / 搬运错；不检交换类错 | 简单    | 简单（加法链）     | **推荐先行**：复刻场景足够，两侧易对齐。 |
| CRC-16/CRC-32          | 检错更强（含部分突发 / 交换） | 简单    | 略复杂（移位多项式链） | 可选加固；若累加和满足则不引入。       |

校验粒度先按**整体一份校验和**；逐段校验作为可选（段表项可加段内校验字）。

### 4.4 打包 / 装载 / 校验链路分段



1. **打包侧（tape-converter 家族新增&#x20;**`image-pack`**）**：输入多段 `.103` + 段清单（目的地址、段类型、字数、入口 PC）；输出结构化镜像容器（目录头 + 段表 + 镜像体 + 校验和）。与现有 char2tape 汇编方向并存：纸带通路保留给基线回归，镜像通路服务独立启动场景。

2. **simulator 装载侧**：新增可选镜像路径（如 `-m <image>`）。启动序：读镜像 → 校验魔数 → 复核校验和 → 按段写 `machine_mem` → 置入口 PC；校验失败 / 越界走非零退出码与报错信息。旧纸带通路默认不变，保基线零回退。

3. **RTL 装载侧**：测试台 / 加载器模型读镜像（文本镜像 `$readmemh` 或经 dbg 通道逐段落主存），遍历段表写入并复核校验和；校验失败、类型不符、越界 entry 走断言 / 判据失败。上板再换 SPI NOR 控制器 + 引导 FSM，段表与校验口径不变。

4. **生成 / 回归链接入**：`regenerate-test-program.ps1` 增一路镜像产物（与 `.103/.bin` 并列）；冻结参考目录相应增镜像样例。

### 4.5 定向用例（报错路径覆盖）



* 镜像文件缺失 / 打不开；

* 魔数错（非合法镜像）；

* 校验和不匹配；

* 段类型为保留 / 未知类型；

* 目的地址越界、目的 + 字数超 12 位地址空间；

* 段字数为 0 / 段数 N=0；

* 入口 PC 越界；

* （正向）合法多段镜像装载后，目的区逐字等于镜像体，入口执行结果与基线一致。

## 5. 介质定档与待拍板项推荐意见

### 5.1 介质已定：外挂 SPI NOR Flash

- 引导介质为**外挂四线 SPI NOR Flash**（CS# / CLK / MOSI / MISO，SPI Mode 0/3）。
- FPGA 引导期**只读**：上电由引导 FSM 发线性读命令（03h）取目录与镜像体；NOR 的写/擦除由量产烧录工具/下载器完成，引导链路不实现页写/扇区擦除。
- 容量口径：主存 2048 字 ≈ 7.75 KiB、4096 字 ≈ 15.5 KiB（31 位字）；一颗小容量 SPI NOR（1–4 MB）可放多份镜像 + 目录，24 位字节偏移覆盖 16 MB 空间。
- 现状核对：`hardware/shell/hardware_top.v` 当前仅有 74lv165 输入链 / 74lv595 输出链，**无 SPI 控制器与 Flash 接口**；SPI 主控制器 + 引导加载 FSM 为全新外设挂载。

### 5.2 其余项推荐意见（待确认后冻结）

| # | 待拍板项 | 推荐 | 依据 |
| --- | --- | --- | --- |
| 1 | 范围分层 | **路线 A 仿真镜像闭环先行**；路线 B（SPI NOR 控制器 + 引导 FSM）本轮只定端口契约与模块边界，SPI 移位时序 / 上板综合留后 | 现有无 SPI 接口、无板级引脚与时序约束；先在仿真打通目录遍历/校验/装载口径，上板再接物理层，避免未验证链路硬上 |
| 2 | 校验算法 / 粒度 | 仿真闭环先用**按字累加和**（mod 2³¹，符号位单独累加）；目录头预留算法标识位，上板阶段升级 **CRC-16**。粒度先**整体一份校验和**，段内校验字预留不强制 | 累加和 C/RTL 最简，先拿可回归出口；CRC 升级不动目录结构。SPI NOR 多无片上 ECC，长期 CRC 检错覆盖更强，符合 Flash 应用惯例 |
| 3 | 镜像物理格式 | **二进制 `.bin` 为烧录主格式**（直接对应 NOR 字节流）；派生两份文本：`.lst` 带注释十六进制清单供 diff / 冻结参考，`.hex` 纯十六进制（每行一字）供 RTL `$readmemh` 装载；与现有纸带 `input.bin` **并存**（纸带保基线回归与手动录入，镜像服务独立启动），不替代 | NOR 按字节编址，烧录对象即二进制映像；文本不可直接烧录。字打包 31→32 位（4 字节/字，bit31 预留），对齐 4a §6 位宽口径；`num_t` 本就是 32 位容器 |
| 4 | 段类型 / 段数上限 | **不设栈段**；类型枚举 `0=程序段、1=常量/数据段、2=保留`；段数上限工程取 **16**（目录头段数字段留 12 位余量） | 指令集核对：仅有无条件/条件转移（24/34/64/74），无 CALL/RET/PUSH/POP，无栈操作概念 |
| 5 | 装载前清零 | **先清零主存再按段写入**；simulator `init_mem` 配套补 memset 清零（修掉当前只 malloc 未清零、未覆盖地址为垃圾值的现状）；RTL 加载器复位后先清主存 | BRAM / 堆上电不定，未装载地址必须确定，避免垃圾值参与运算 |
| 6 | 段表源地址口径 | 用 **NOR 镜像体内偏移**（紧凑排列），不用主存绝对源地址；**路线 A 落地偏差**：单字放不下 12 目的 + 24 偏移 + 3 类型 + 4 标志，偏移字段降级为 12 位 body 内字索引 `[23:12]`（定位 ×4 即字节偏移）；24 位绝对 NOR 字节偏移留待路线 B，段表项扩第三字承载，两侧打包/装载口径不变 | 真实引导是 NOR→主存直写，主存内无预填源区；现有"源区在主存"是仿真预填口径，不进真实段表 |

### 5.3 SPI NOR 引导边界（路线 B 预留，本轮不实现）

- 新增 `spi_nor_loader` 模块 = SPI 主控制器（CS#/CLK/MOSI/MISO，Mode 0）+ 引导 FSM：上电 → 发 03h 读命令 + 24 位地址 → 读目录头 → 校验魔数/校验和 → 遍历段表 → 按段写主存 → 置入口 PC → 释放核心运行。
- 接口契约：loader 写主存复用既有仲裁写口；完成/状态信号接核心启动寄存器。
- 本轮只定模块端口与 FSM 状态划分，不实现 SPI 移位时序、不做上板综合。

### 5.4 镜像布局（32 位字容器，4 字节/字）

| 区域 | 字段 | 位宽建议 |
| --- | --- | --- |
| 目录头 | 魔数 MAGIC；段数 N；入口 PC；版本 / 校验算法标识 | 31 位；`[11:0]`；`[23:12]`；`[30:24]` |
| 段表（2 字/段） | A：目的地址 dst `[11:0]`、body 内字索引 off `[23:12]`、段类型 `[26:24]`、标志 `[30:27]`；B：字数 len `[11:0]`、预留 | 见 §5.2-6。**落地偏差**：off 为 12 位字索引（非 24 位绝对字节偏移）；路线 B 多镜像分区时由第三字承载绝对偏移 |
| 镜像体 | 各段 32 位字按段顺序紧凑排列 | 32 位/字（bit31 预留） |
| 校验尾 | 整体校验和（覆盖目录头 + 段表 + 镜像体） | 31 位 |

## 6. 与其他 P0 项的依赖



* **P0-1（主存 BRAM 收敛）**：已落地（4e），与 P0-2 独立并行；镜像加载器写主存走既有仲裁写口，不改变 P0-1 端口模板。

* **P0-3（综合 / 时序评估）**：镜像加载器若落到 RTL，其目录遍历 / 校验逻辑为小容量控制逻辑，不占块 RAM；综合资源评估在 P0-3 链路上复核。

* **dbg 预填通路**：4e §6.1 已定 dbg 为仿真专用、量产移除；路线 A 的 RTL 镜像加载器是 dbg 预填在独立启动场景下的替代通路之一，路线 B 落地后二者一并收敛。

## 7. 路线 A 落地验证记录（2026-11-25）

### 7.1 实现清单

* **打包器 `image-pack`**（`tape-converter/src_imagepack/`：`main.c` + `image_format.h` + `Makefile`）：读 `.seg` 段定义（八进制 entry/seg）+ `.103` 文本，边界校验后组装小端 32 位字流，产出 `.bin`（烧录主格式）、`.lst`（带注释十六进制清单）、`.hex`（纯十六进制每行一字，供 RTL `$readmemh`）。
* **simulator 装载侧**（`simulator/src_c/`）：`103.c` `init_mem()` 补 memset 清零；新增 `load_image()`（魔数/版本/算法/段数/入口/类型/字数/目的/偏移/整体校验和逐项校验，失败非零退出 + stderr 报错；通过则清零主存、按段写入、`set_pc(entry)`）；`main.c` 增 `-m/--image` 选项，与旧纸带通路二选一。
* **RTL 行为加载器**（`work/rtl/image_loader.v`）：FSM `IDLE/CHECK/WIPE/LOAD/DONE/ERROR`，内部 `$readmemh` 读 hex，解析目录头/段表/校验尾并复算累加和，先经 dbg 写口清零全主存再逐段装载；输出 `loader_wr_en/addr/data`、`loader_done/err/err_code/entry`。报错码与 C 侧对齐（0 OK；1 空/过短；2 魔数；3 版本/算法；4 段数；5 入口越界；6 类型；7 字数 0；8 目的越界；9 偏移越界；10 校验和；11 镜像体字数不符）。
* **测试台**：`tb_image_loader.v`（正向：memory + loader 集成，逐段读回比对、未装载区清零抽查、入口核对）；`tb_image_loader_err.v`（报错路径：断言 ERROR、错误码匹配、出错后不再写主存）。
* **回归脚本**：`tools/regress-image-loader.ps1`（打包 → C 正向 MD5 比对 → C 报错分支 → RTL 正向 → RTL 报错分支，汇总 PASS/FAIL）。

### 7.2 基线与回归结论

* **04_and 镜像通路正向基线**：`output.103` MD5 `00a84cb87f46cbab5a2e0f1f73a909d2`（320 行），与冻结参考逐行一致。镜像样例：程序段 0000–1200（641 字）、数据段 3000–3777（512 字），共 1153 字；hex 1160 字 = 2 头 + 4 段表 + 1153 body + 1 尾字。
* **C 侧报错分支**：魔数错、校验和不符、类型保留、目的越界、字数 0、段数 0、版本不支持、算法不支持、偏移越界、镜像体字数不符 —— 10 例全部非零退出且 stderr 命中对应报错。
* **RTL 报错分支**：魔数(2)、校验和(10)、类型(6)、目的越界(8)、字数 0(7)、段数 0(4)、版本/算法(3)、偏移越界(9) —— 9 例 `RESULT: PASS`；出错后无后续写主存。
* **旧纸带通路零回退**：模拟器回归 PASS 17 / DIFF 0 / N/A 3（09_strt、10_pnl、11_sw 面板类）/ 无输出 0；汇编一致性 PASS 20 / DIFF 0。既有内核 RTL tb 全绿（engine-mem / engine-ctrl / fw-poll / inst-cov / move-cov / sub / abs / cpu-eng-concur / engine-core / core-eb / io-cases）。
* **入口 PC 越界分支备注**：12 位地址天然 `< 4096`，路线 A 无法在编码上构造越界 entry，该检查为防御性保留；上板地址空间口径变化时再补定向用例。
