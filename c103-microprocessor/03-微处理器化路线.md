# 03 微处理器化路线

## 1. 已有基础（工程现状）

- 存在可综合的同步 RTL：`../hardware/core/` 下译码、节拍、发射、PC、MAR、ALU 各模块齐全。
- 存在 ASIC SRAM 包装：`memory_asic.v` 例化 8 块 `S011HD1P_X32Y2D128_BW` SRAM 宏。
- 存在行为回归基线：C 模拟器 + Verilator 链路，冻结基线 17 PASS / 0 DIFF / 3 N/A；char2tape 汇编一致性 20/20。
- 已有乘除 64 位独立 Python 核对模型与固定种子用例重生成链路。

## 2. 三条演进路径

| 路径 | 做法 | 前提条件 | 评价 |
|---|---|---|---|
| A. FPGA 软核 | 现有 RTL 综合到 FPGA 板级 | 补工程约束：`.gprj/.cst/.sdc/.xdc`（仓库当前缺失）；板级外设与下载链路 | 最快可演示；当前卡在工程约束与板级集成，不在内核 |
| B. ASIC 单片 | 综合 + 布局布线，SRAM 宏已包装 | 时序收敛、功耗/面积评估、后端流程；工艺选型 | 研究/流片演示性质，无产品必要 |
| C. 软核 IP | 以可综合核 + 外设桥接层形式交付 | 接口规范、验证套件、文档 | 最适合教学/复刻项目复用 |

## 3. 不可复刻与不做的部分

- **电子管工艺不可复刻**：原机器件级工艺（电子管、继电器式面板）不在硅片软核复刻范围内；复刻对象是逻辑架构与指令语义。
- **产品化无意义**：双地址内存—内存模型、定点 30 位、2048 字规模在通用计算/嵌入式市场无竞争力；不把复古架构包装成先进设计。

## 4. 价值定位

| 价值类型 | 说明 |
|---|---|
| 教学样本 | 早期计算机架构、双地址编码、操作码变体副作用、面板可观测性的直观教材 |
| 历史遗产 | M-3 / 103 谱系的数字保存与可运行复刻 |
| 架构谱系研究 | 观察操作码变体编码、结果留存复用等早期设计思想如何被现代架构吸收超越 |
| 复刻工程训练 | 工具链、仿真回归、外设现代化、软核集成的完整演练载体 |

## 5. 演进总原则

- **内核保真**：定点语义、指令行为、寄存器模型与原机一致，回归用例作兼容锁。
- **外设可重写**：面板、纸带、I/O 打包解包等外围层允许现代化替换（见 `05-外设现代化分层.md`）。
- **特性标注**：后续新增的栈、中断、浮点、缓存等架构特性必须与忠实内核明确区分、单独标注。
