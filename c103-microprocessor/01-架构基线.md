# 01 架构基线

> 本文汇总经本地 RTL / C 模拟器源码核实的机器性质。指令逐条语义见 `../103机指令集表.md`，模块接线见 `../Computer-103-数据通路拓扑.svg`。

## 1. 机器性质一览

| 维度 | 结论 | 依据 |
|---|---|---|
| 数制 | **二进制定点**；十进制/八进制只出现在 I/O 界面层（BCD / 八进制打包） | 模拟器数值掩码、RTL 全链路 31 位 |
| 字长 | 31 位 = 1 符号位 + 30 位数值位；bit31 不用 | RTL `memory_fpga.v` 全链路 `[30:0]`；模拟器符号掩码 `0x40000000`、数值掩码 `0x3fffffff` |
| 编码 | **符号—数值码**（sign-magnitude），非补码 | 模拟器符号/数值分离处理 |
| 数值定标 | 定点小数；乘 `(B·A)>>30`，除 `(B<<30)/A`；溢出报错退出 | `103.c` do_mul / do_div |
| 架构类型 | **双地址内存—内存型**，不是典型单地址累加器机；运算器内 B 寄存器承担累加器型结果留存角色 | 指令同时拆 c1/c2，两条取数通路 A/B |
| 存储规模 | 2048 字 × 31 位 ≈ 7.75 KiB | 模拟器 `malloc(04000)`；RTL BRAM 2048×31 bit |
| 寻址 | 12 位扁平地址，指令内直接地址；**无索引寄存器、无间接/自增寻址** | 模拟器译码 c1/c2 直接取 mem |
| 中断 | **无中断机制**，I/O 全靠轮询握手 | core_top 仅 dev 握手信号 |
| 栈 / 调用 | **无栈、无栈指针、无 CALL/RET** | 指令集无调用返回码；只有转移类指令 |

## 2. 指令格式

31 位指令字：

```
[30] 符号 | [29:24] 操作码 6 bit | [23:12] c1 12 bit | [11:0] c2 12 bit
```

八进制书写：`± 操作码 c1 c2`。

- 操作码拆为 `op1`（高 3 位，变体/副作用）与 `op2`（低 3 位，操作）。
- 算术 op2：0 加、1 减、2 除、3 乘、6 逻辑乘（按位 AND）。
- op1 变体：是否写回、是否打印、是否取模、是否复用 B 中上次结果。
- 完整矩阵与非算术码（输入/传送/转移/条件转移/停机变体）见 `../103机指令集表.md`。

## 3. 寄存器模型

| 寄存器 | 模拟器 | 角色 |
|---|---|---|
| A | `reg_a` | 第一操作数 |
| B | `reg_b` | 第二操作数 / 结果留存 / 条件转移判据 |
| C | `reg_c` | 指令字 / 结果 / 中转 |
| Д | `reg_d` | 原机并行加法器/进位链；模拟器仅占位 |
| PC | `reg_pc`（ПР） | 程序计数器 |
| СР | `select_reg` | 地址寄存器 + 比较 |

补充：原机另有 АУ / СР / ПР 寄存器预置分工，停机变体的差异体现在这些面板可见寄存器的预置上；模拟器以 break 退出建模。

## 4. 数据通路与 I/O 模型（RTL 核实）

- 取指：PC → MAR → 取指令字 → 译码（op1/op2/c1/c2）。
- 算术：c1 取数入 A，c2 取数入 B（部分变体复用上次结果），运算结果写回 B；按 op1 决定是否写内存、是否打印、是否取模。
- 对外设备口：5 位双向握手——输入 `rdy/val`，输出 `rdy/ack`；io_unit 内移位拼装/拆解 31 位字。
- 内存写：地址来自 select_reg，写数据来自 arith_unit，写使能来自 io_unit 或面板脉冲；存储器当前只有 CPU 一个写主。
- 核心对外接口（`core_top.v`）：`dev_input_val/rdy`、`dev_output_ack/rdy`、5 位数据，以及一组 `pnl_*` 面板脉冲/电平调试信号。

## 6. 基线对后续演进的约束

1. 无栈、无 CALL/RET → 任务切换与子程序调用必须另建静态约定（见 `06-协作式固件方案.md`）。
2. 无索引/间接寻址 → 连续块装载不能靠指令自增遍历，需软件自修改代码或硬件拷贝引擎（见 `07-硬件拷贝引擎设计.md`）。
3. 无中断/定时器 → 抢占式调度、定时节拍不可原生实现（见 `02-现代类比与可行性评估.md`）。
4. 2048 字规模 → 多任务、常驻控制台、镜像目录必须先扩地址空间。
