# 04 FPU 集成设想

## 1. 总体方案

**推荐独立协处理器式 FPU：主核定点不动，浮点运算由协处理器完成。**

- 主核保持 31 位定点、符号—数值码的原语义；
- FPU 作为现代化外设/协处理器挂接，不改动内核定点数据通路；
- 浮点能力属于"后加特性"，与忠实内核明确区分标注。

## 2. 保真边界

| 层 | 可否改动 | 说明 |
|---|---|---|
| ISA / 定点语义 | 保真 | 定点指令行为、溢出/取模/符号规则保持原机口径 |
| 外设与表示层 | 可重写 | 浮点表示、打包格式、I/O 呈现可现代定义 |
| 浮点指令编码 | 需新增 | 原指令集无浮点码，编码空间与触发方式另定 |

## 3. 浮点表示选型（待选型）

| 选项 | 说明 |
|---|---|
| 31 位短浮点 | 与原字长对齐，单字存放；精度有限 |
| 双字浮点 | 两个 31 位字拼一个浮点值，精度更高；需双字存取约定 |

定点小数定标（乘 `>>30`、除 `<<30`）是原机算法规约；浮点 FPU 不继承该定点定标，另设尾数/指数格式。格式路线已选定**路线甲（复古 Zuse 风格自定义浮点）**，见 §7.5；暂定位域约定见 §7.6。

## 4. 需要补齐的软硬件清单

### 4.1 硬件 / RTL

- 浮点指令编码与译码入口；
- 浮点寄存器组（或浮点上下文槽）；
- FPU 状态机节拍：取操作数、运算、舍入、写回、握手；
- 加/减/乘/除浮点数据通路；
- 舍入模式支持（至少一种默认舍入，其余按需）；
- 异常/状态标志（溢出、下溢、除零、无效）的上报通路。

### 4.2 软件 / 工具链

- 浮点调用约定：操作数与结果在主存/协处理器间的传递协议；
- 汇编/宏层浮点助记符映射；
- 编译器后端或手工定点/浮点库；
- 浮点用例与独立核对模型（对照定点 oracle 的做法，另建浮点数值 oracle）。

### 4.3 验证

- FPU 定点回归不被破坏：现有 17 PASS 基线保持；
- 浮点边界用例：零、符号、规格化/非规格化、溢出/下溢、除零；
- 协处理器握手时序仿真（Verilator 链路）。

## 5. 与主核的耦合方式（设想）

- 主核经命令/数据握手把浮点操作数送入 FPU，FPU 完成后回写结果；
- 无中断前提下，主核轮询 FPU 完成状态（与协作式固件的轮询模型一致）；
- FPU 不参与主核节拍链，避免牵动原机脉冲时序。

## 6. 边界提醒

- FPU 是研究/教学增强项，不改变"103 原生只做定点"的历史事实；
- 不建议在忠实内核内强行改定点 ALU 为浮点通路；协处理器隔离是改动面最小的路线。

## 7. Z3 / Z4 历史参照评估（2026-11-26 补）

### 7.1 结论

Z3/Z4 作为**同时代浮点架构的历史参照**采用，不作为 FPU 的改造基型：可借浮点格式划分、指数/尾数双通路分解和特殊值模型；继电器电路、纸带控制时序与非 IEEE 语义不照搬。

史实对照：Zuse 一支在 1940 年代即选硬件浮点，M-3/103 一支走定点符号—数值码路线，两者是早期计算架构的两个分叉。把 Zuse 浮点思路挂到 103 软核上，定位是"给定点原生机补一个同时代风格的浮点协处理器"，题材成立。

### 7.2 Z3 / Z4 规格对照（核实口径）

| | Z3（1941） | Z4（1942–45，1950 交付 ETH） |
|---|---|---|
| 数制 | 二进制浮点 | 二进制浮点，十进制出入 |
| 字长 | 22 位：1 符号 + 7 指数 + 14 尾数 | 32 位：尾数 24 位（含符号）+ 指数 7 位（含符号，−63…+63）+ 特殊值 1 位 |
| 存储 | 64 字，继电器/机械存储 | 64 字机械存储 |
| 运算 | 加、减、乘、除、开方、十/二转换；异常值 ±∞、未定义可参与运算 | 加、减、乘、除、开方、MAX、MIN、符号位、正弦；含无穷/NaN 测试；1950 年补条件跳转 |
| 控制 | 穿孔胶片纸带，无跳转指令 | 双读带；条件跳转后加 |
| 器件 | ~2600 继电器，5.3 Hz；加 0.8s / 乘 3s | ~2500 继电器，约 4 kW |

来源：ZIB Konrad Zuse 档案（Z3 重建说明 / Z4 条目）、Horst Zuse《Konrad Zuse's Computer Z3》技术报告。

### 7.3 可借鉴点

1. **指数/尾数双通路分解**：Z3 运算器左右两半，一组寄存器与 ALU 处理指数，另一组处理尾数；FPU RTL 可直接照此拆为 exponent unit + mantissa unit，不混在一条通路里。
2. **寄存器对表示浮点数**：`(指数, 尾数)` 成对存放，与 §4.1 浮点寄存器组/上下文槽设想对应。
3. **特殊值先行建模**：±∞、未定义数产生并透传参与后续运算；配无穷/NaN 测试，对应 §4.1 异常标志（溢出、下溢、除零、无效）上报通路。
4. **指令集规模参照**：加减乘除 + 开方 + MAX/MIN/符号；正弦在 Z4 中为步进开关控制的慢速算子，不纳入硬件 FPU 范围。

格式上，Z4 的 32 位划分（符号 + 7 位有符号阶 + 24 位尾数/特殊值）可作为 §3 "31 位短浮点"方案的历史变体蓝本，与对齐原字长的思路兼容。

### 7.4 不可照搬项

1. **实现载体无法移植**：继电器/步进开关的串行节拍与触点连线在 FPGA 上无对应物，继承范围仅限算法与状态划分。
2. **控制模型对不上**：Z3/Z4 是纸带驱动的整机串行控制器；本项目 FPU 是内存映射命令块 + 轮询握手的协处理器，外壳沿用现有 `engine_ctrl` 模型，不照 Zuse 纸带时序。
3. **语义非 IEEE-754**：指数为带符号位阶、无现代偏置阶码；无渐进下溢（非规格化数）；早期机型舍入多为截断；∞/未定义运算规则自成一套。直接与现代浮点库对拍需自建全套规则 oracle。
4. **速度数字无参考价值**：继电器节拍（加 0.8s、乘 3s）不传导到 RTL，上板后只看数据通路级数与 Fmax。

### 7.5 格式路线：路线甲（已选定，2026-11-26）

**选定路线甲：复古 Zuse 风格自定义浮点。** 选定理由：目标平台无标准浮点库、无高级语言后端，IEEE-754 的生态兼容收益接近零；自定义一套可主动裁掉非规格化数、多舍入模式、NaN 载荷传播等合规表面，题材也与项目复古定位一致。

需要明确：省掉的是 IEEE 合规兼容成本，**FPU 核心数据通路工作量不随格式减小**——指数对齐、尾数加减/乘除、规格化、特殊值 FSM、边界用例与 oracle 两条路线都要做。

| | 路线甲 ✅ 已选定：复古 Zuse 风格浮点 | 路线乙（不采用）：现代单精度 IEEE-754 |
|---|---|---|
| 格式 | 仿 Z4 划分，31 位单字自定义格式 | 标准 32 位单精度，双字槽存放 |
| 参照 | Z3/Z4 双通路分解、特殊值透传、测试指令 | 经典 FPU 数据通路 |
| 优点 | 题材统一、教学叙事完整、字长贴合原机；无生态兼容包袱 | 数值库/交叉核对成熟，可对接标准 oracle |
| 代价 | 语义自定义，浮点库与边界用例全部自建 | 与"1950 年代风格"叙事弱关联，且本目标用不上其生态价值 |
| 适用 | 研究/展览向原型（本项目定位） | FPU 真正对接现代科学计算生态 |

路线甲不改变 §2 保真边界与 §5 耦合方式：主核定点语义不动，FPU 独立协处理器隔离，轮询完成，不参与主核节拍链。Zuse 参考只影响 FPU 内部格式与算法风格。

### 7.6 暂定格式约定草案（细节待规范文档冻结，冻结前不进 RTL）

| 项 | 暂定约定 | 备注 |
|---|---|---|
| 字长 | 31 位单字，与原机字长对齐 | 双字浮点槽留作后续扩展，本期不做 |
| 位域 | 1 符号 + 7 位阶 + 23 位尾数 | 隐藏位是否启用待最终定；启用则尾数有效位 24 |
| 阶码 | 偏置码（不沿用 Zuse 带符号阶） | 偏置值待规范定；偏置码简化比较/对齐电路 |
| 舍入 | 截断（先只做一种） | 就近舍入列为后续可选项 |
| 下溢 | 不做渐进下溢；flush 到零/∞ 并置状态标志 | 非规格化数不建模 |
| 特殊值 | ±∞ + 一个"未定义"（NaN 类） | 对齐 Z3/Z4；参与运算规则待真值表冻结 |
| 状态标志 | 溢出 / 下溢 / 除零 / 无效 | 经协处理器状态回写，主核轮询读取 |

**待细化项**（规范文档冻结前不进 RTL）：偏置值、隐藏位取舍、特殊值编码与参与运算真值表、零/符号规则、十进制出入换算格式。
