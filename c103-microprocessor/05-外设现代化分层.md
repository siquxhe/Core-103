# 05 外设现代化分层

## 1. 分层模型

```
┌─────────────────────────────────────────────┐
│ 现代外设 IP：Flash/ROM 镜像区、拷贝引擎、      │
│  控制台串口、定时器（后加）、显示等            │
├─────────────────────────────────────────────┤
│ 外设桥接层：握手协议适配、打包/解包、地址映射  │
│  （替换原 io_unit + shell 驱动角色）           │
├─────────────────────────────────────────────┤
│ 忠实内核 core_top：译码/节拍/发射/PC/MAR/ALU  │
│  定点语义与指令行为保持原机口径                │
└─────────────────────────────────────────────┘
```

### 1.1 忠实内核层

- 范围：`hardware/core/` 内译码、节拍、运算、寄存器、内存模型。
- 原则：指令行为定点保真，回归用例作兼容锁；不为现代化便利改 ISA 语义。

### 1.2 外设桥接层

- 原机 io_unit 承担的 I/O 拼装/拆解、握手时序，以及 shell 下面板/开关/脉冲驱动，归入此层。
- 打包解包（八进制/十进制 BCD、5 位符号流 ↔ 31 位字）下沉到桥接层，不污染内核。
- 桥接层可整体替换为现代总线/IP 适配，内核接口保持不变。

### 1.3 现代外设 IP 层

- 块拷贝引擎（见 `07-硬件拷贝引擎设计.md`）；
- Flash/ROM 镜像存储；
- 控制台串口/显示；
- 后加特性：定时器、中断控制器、FPU 协处理器（各自独立标注）。

## 2. 兼容锁

- 现有 17 PASS / 0 DIFF / 3 N/A 回归基线作为内核兼容锁；
- 外设替换不得改变定点指令的输入/输出数值与停机行为；
- 新增外设带来的用例单独成组，不混入历史基线。

## 3. 架构特性新增规则

以下特性原机没有，若在软核上新增，必须单独标注为"现代增强"，不计入忠实复刻：

- 栈与 CALL/RET；
- 中断 / 定时器 / 节拍；
- 浮点单元；
- 缓存、索引/间接寻址；
- 内存保护、特权级。

## 5. 现代化重写的边界

- **可以重写**：外设控制器、面板/启动接口、存储介质模型、打包解包层；
- **不应重写**：内核译码与定点语义、指令编码约定、寄存器分工的历史口径；
- **诊断结论**：当前项目卡点在外围（外设控制器 + 前面板调试/启动接口 + 板级集成），不在内核命令处理器。
