## 4. 总判断（一句话）

103 的通用计算与产品化价值已被现代架构全面超越，但作为可综合的历史架构样本，**可以在软核/外设现代化前提下做成教学与研究用途的微处理器形态**；演进路线选定为：内核定点语义保真、外设分层重写、固件走协作式静态调度、块装载由硬件拷贝引擎承担；不追求原生跑现代 OS 或抢占式 RTOS。

## 5. 口径说明

- 结论区分三类：**事实**（本地 RTL / 模拟器源码或史料可核）、**推断**（基于架构约束的设计判断）、**未知**（待原始手册或上板验证）。
- 速度、内存容量、产量等数字各史料有区间差异，引用时给区间并区分配置，详见 `08-边界风险与未决项.md`。
- 英文 Wikipedia DJS-1 摘要一处误写 "based on M-1"，以 M-3 为准。
